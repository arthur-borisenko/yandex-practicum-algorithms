# My solutions of Yandex Practicum course "Algorithms and Data Structures"

### My solutions for the Yandex Practicum course on Algorithms and Data Structures. All tasks were solved on python.


## Objectives Learned

### Sprint 1 - Basics of Python
- input/output handling
- Linear search
- Time complexity estimation and optimization basics

### Sprint 2 - Basic Data Structures
- **Fixed-size arrays**: Implemented ring buffer using array-based storage with modulo indexing
- **Linked lists**: Built singly linked list with append, insert, and delete operations
- **Stacks**: Created stack class supporting push/pop with O(1) operations
- **Queues**: Implemented queue using fixed-capacity array with head/tail pointers
- **Deque**: Implemented double-ended queue with O(1) insertion/removal at both ends

### Sprint 3 - Recursive Algorithms and Sorting
- **Binary search**: Implemented iterative and recursive versions for sorted arrays
- **Bubble sort**: Basic O(n²) sorting
- **Insertion sort**: Another O(n²) sorting
- **Merge sort**: O(n log n) sorting algorithm
- **Counting sort**: Linear-time non-comparison sorting for integers within limited range

### Sprint 4 - Hash Tables
- **Hash tables with chaining**: Implemented hashmap-like structure using chaining and open-addressing collision resolution
- **String hashing**: Implemented polynomial hash with modulo arithmetic
- **Rabin-Karp algorithm**: Implemented substring search using hashing technique

### Sprint 5 - Trees
- **Binary trees**: Traversal methods (in-order, pre-order, post-order)
- **Binary search trees (BST)**: Insertion, search, and deletion operations
- **AVL Tree**: BST with balancing
- **k-th smallest element**: Augmented BST nodes to support rank queries
- **Tree traversal**: Tree BFS and DFS algorithms

### Sprint 6 - Graphs
- **Graph representation**: Adjacency list implementation for sparse graphs
- **DFS (Depth-First Search)**: Both recursive and iterative implementations
- **BFS (Breadth-First Search)**: Shortest path finding in unweighted graphs
- **Topological sorting**: Implemented topological sorting for DAGs
- **Connectivity detection**: Component identification in undirected graphs
- **Minimum spanning tree**: Kruskal's algorithm
- **Dijkstra's algorithm**: Shortest paths in weighted graphs using priority queue
- **Floyd-Warshall algorithm**: All-pairs shortest paths computation
- **Eulerian path detection**: Checked vertex degrees for Eulerian conditions

### Sprint 7 - Dynamic Programming
- **Memoization**: DP with caching for overlapping subproblems
- **Tabulation**: State building for knapsack-type problems
- **Classic problems solved:**
  - Edit distance (Levenshtein distance)
  - Knapsack problem variants
  - Fibonacci sequence
  - Longest increasing subsequence
### Sprint 8 - String-based algorithms
- **basics of strings: basic operations, substrings, prefixes and suffixes**
- **Prefix function**
- **Classic problems solved:**
  - Efficient substring search
  - Longest common prefix
  - Longest repeat
